# Классификация гамма-событий — MAGIC Gamma Telescope

Учебный проект по анализу данных и бинарной классификации. Цель — по параметрам изображения атмосферного ливня отличать гамма-события (сигнал) от адронного фона.

## Данные

Использован [MAGIC Gamma Telescope](https://archive.ics.uci.edu/dataset/159/magic+gamma+telescope) из UCI Machine Learning Repository. Набор получен моделированием методом Монте-Карло и содержит **19 020 наблюдений**, **10 числовых признаков** и метку класса (`g` — гамма, `h` — адрон). Признаки описывают геометрию и интенсивность изображения, в том числе `fLength`, `fWidth`, `fSize`, `fConc`, `fConc1`.

В выборке **12 332 гамма-события (64,8%)** и **6 688 адронных событий (35,2%)**. Пропущенных значений нет. Найдено **115 повторяющихся полных строк**; они оставлены, поскольку по признакам нельзя установить, относятся ли совпадающие записи к одному событию.

## Этапы работы

1. Проверка структуры и качества данных, описательная статистика, графики распределения классов и корреляций.
2. Разделение на обучающую (80%) и тестовую (20%) выборки со стратификацией. Стандартизация в `Pipeline` для SVM и Logistic Regression.
3. Сравнение алгоритмов: Logistic Regression, SVM, Decision Tree, Random Forest, XGBoost, LightGBM, CatBoost. В качестве ориентира — Baseline, предсказывающий наиболее частый класс.
4. Пятикратная стратифицированная кросс-валидация на обучающей выборке по Accuracy, Precision, Recall, F1 и ROC-AUC.
5. Исследование влияния балансировки классов на Random Forest: без балансировки, `class_weight='balanced'` и SMOTE. SMOTE применяется только внутри обучающих фолдов.
6. Проверка влияния исключения коррелирующего признака `fConc1` на Logistic Regression.
7. Оценка выбранной по F1 модели на тестовой выборке, матрица ошибок и ROC-кривая.

## Результаты

Средние значения на пяти фолдах кросс-валидации (положительный класс — гамма):

| Модель | F1 | ROC-AUC |
|---|---:|---:|
| LightGBM | **0,9115** | **0,9356** |
| XGBoost | 0,9100 | 0,9335 |
| CatBoost | 0,9090 | 0,9311 |
| Random Forest | 0,9088 | 0,9333 |
| SVM | 0,9038 | 0,9151 |
| Decision Tree | 0,8512 | 0,8183 |
| Logistic Regression | 0,8494 | 0,8413 |
| Baseline | 0,7867 | 0,5000 |

**LightGBM** получил наибольший средний F1, но разница с другими ансамблевыми моделями небольшая; статистическая значимость различий отдельно не проверялась.

На тестовой выборке у LightGBM: **Accuracy ≈ 89,1%**, **ROC-AUC = 0,9425**. По матрице ошибок правильно определены **2 337 гамма-событий** и **1 053 адрона**; **285 адронов** ошибочно признаны гамма-событиями и **129 гамма-событий** пропущены.

### Балансировка классов

| Вариант Random Forest | F1 (гамма) | Recall (гамма) | Recall (адроны) |
|---|---:|---:|---:|
| Без балансировки | **0,9088** | 0,9396 | 0,7637 |
| Веса классов | 0,9073 | 0,9342 | 0,7695 |
| SMOTE | 0,8990 | 0,9000 | **0,8118** |

SMOTE помогает распознавать адронный фон, но снижает полноту обнаружения гамма-событий и F1 для положительного класса. Балансировка не дала универсального улучшения качества.

Исключение `fConc1` почти не изменило F1 Logistic Regression: **0,8494** против **0,8487**.

## Как запустить

Откройте `MAGIC_Gamma.ipynb` в [Google Colab](https://colab.research.google.com/) и выполните ячейки по порядку. Первая ячейка установки устанавливает дополнительные библиотеки. Данные загружаются автоматически из UCI через `ucimlrepo`; локальный CSV не требуется. Для воспроизводимости нужен доступ к интернету.

## Ограничения

- Это моделированные события, а не измерения из реальных наблюдений.
- Совпадающие строки оставлены в наборе: возможное влияние повторов на оценку качества отдельно не исследовано.
- Во время предыдущих итераций проекта тестовая выборка уже просматривалась; поэтому результаты на тесте не следует считать полностью независимой оценкой всех исследовательских решений.
- Сравнение способов балансировки выполнено на Random Forest, а не для каждого алгоритма.

Проект выполнен в рамках университетского изучения методов обработки и анализа данных.
